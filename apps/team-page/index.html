힌드사이트 hindsight 유튜버가 말한 종목, 그 뒤에 어떻게 됐나

김지환오선호조인성채재희김현준
문제무엇을화면데이터 구조지킬 것일정·역할확장

1문제

유튜브에서 종목 이야기를 듣고 사는 사람은 많은데, "그 말이 맞았는지"를 사후에 확인하는 사람은 없다.

  • 언급이 갑자기 몰리는 종목은 이미 오른 뒤인 경우가 많다. 그걸 숫자로 보여주는 곳이 없다.
  • "누가 잘 맞혔나"가 아니라 "유튜브 언급을 따라가면 어떻게 되나"라는 현상 자체의 성적을 보여주면, 시청자가 스스로 판단할 수 있다.
  • 사용자: 유튜브로 투자 정보를 얻는 개인 투자자. 사용자 1호는 우리 팀.

2무엇을 만드나

주식·코인 유튜브 채널이 영상 제목에서 언급한 종목을 모아, 언급 뒤 5·20·60 거래일 동안 주가가 실제로 어떻게 움직였는지 통계로 보여주는 서비스.

유튜브 영상 제목→종목 매칭→언급일 기준 주가 추적→5·20·60일 수익률 통계

기존 서비스는 언급량을 세는 데서 끝난다. 우리는 언급 뒤 실제 수익률까지 묶는다.

3화면 3개

① 이번 주 언급 급증

최근 7일 언급이 늘어난 종목 순위. 옆에 "그 종목의 과거 언급 뒤 20일 평균 반응"이 같이 붙는다.

삼성전자 · 언급 12 (직전 4)과거 반응 −6.5%
SK하이닉스 · 언급 6 (직전 3)−13.6%
NVIDIA · 언급 1 (직전 0)+2.6%
예시 형태표본 수 함께 표시

② 언급 뒤에 — 분석 페이지

언급 후 5·20·60일 수익률 분포, 코스피·S&P500·비트코인 대비 초과수익, 상승 확률, 표본 수. 채널은 A·B·C 익명 집계.

표본 444건20일 평균 −4.6% · 상승 42%
<−20% … >+20%수익률 히스토그램

③ 종목 타임라인

종목 하나를 고르면 주가 그래프 위에 언급 시점을 점으로 찍는다. 점 색이 20일 뒤 상승·하락.

초록 상승 · 빨강 하락회색 = 아직 20일 안 지남

+ 데이터 페이지(수업 필수): 출처, 채널 목록(익명), 수집 건수, 매칭 성공률과 못 잡은 제목을 그대로 공개.

범위 (8주차 MVP)

  • 채널: 주식 15 + 코인 5, 최근 1년
  • 종목: 국내 전 상장사 + 미국 주요 종목 + 업비트 코인
  • 매칭: 제목에서 종목명·별칭 정확 매칭
  • 통계: 5·20·60일 수익률, 벤치마크 대비 초과수익, 표본 수

매칭이 핵심이다

  • 긴 이름 우선 ("삼성전자우" > "삼성전자")
  • 흔한 단어(KT·삼성·현대·리스크)는 단독 매칭 금지
  • 별칭 사전(삼전·하닉·엔비디아…)은 팀이 계속 보강
  • 못 잡은 제목은 버리지 않고 남겨 성공률로 공개

5구조 — 서비스 4개, 각자 데이터 하나씩

stats언급 뒤 주가는 어땠나 — 수익률·초과수익·요약
mentions이 영상이 어떤 종목을 말했나 — 매칭·성공률
↓ REST 로만 묻는다 · 순환 없음 ↓
youtube어떤 채널이 언제 무슨 영상을 올렸나 (수집 전용)
market-data종목 사전 + 일별 시세 + 지수 (수집 전용)

매일 새벽 순서: market-data(사전·시세) → youtube(새 영상) → mentions(매칭) → market-data(새로 언급된 종목 시세) → stats(수익률). 화면은 계산하지 않고 저장된 결과만 읽는다.

스택: FastAPI + PostgreSQL(Supabase, 서비스별 스키마) + React. 배포: Vercel(프론트) · Render(백엔드 4개) · GitHub Actions(수집 스케줄). API 명세(OpenAPI)를 먼저 쓰고 CI 가 스타일·하위 호환을 검사한다.

6지킬 것

채널은 익명

화면·통계·발표 어디에도 채널 실명 랭킹을 내지 않는다. A·B·C 코드로만 집계한다.

추천하지 않는다

통계와 표본 수만 보여준다. 표본 30건 미만은 "참고용"으로 표시한다.

공개 메타데이터만

영상 제목·게시일·조회수만 쓴다. 자막·댓글은 수집하지 않는다.

8확장 아이디어와 비즈니스

트럼프 발언 → 주가 확장

같은 뼈대("사건 → 이후 주가")에 사건 출처를 하나 더 붙이는 것이라 구조 변경이 없다. 발언 데이터는 X API 가 유료라 뉴스 헤드라인(네이버 뉴스 API, "트럼프" 검색)을 사건으로 쓰는 것이 현실적. 관세·반도체 등 키워드별로 관련 업종·지수의 이후 반응을 비교.

그 밖의 확장

  • 언급 급증 신호를 따라 샀을 때의 백테스트
  • 조회수 가중 "언급 강도"
  • 관심 종목에 새 언급이 뜨면 알림
  • 자막·LLM 기반 종목 추출(후속 과목)

비즈니스 모델

  • 개인 구독: 관심 종목 언급 알림
  • 증권사 리서치·콘텐츠 팀에 "지금 화제인 종목" 데이터
  • 광고·마케팅사 대상 언급량 데이터 API
