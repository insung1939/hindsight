## 3. 발표에서 데이터 장을 어떻게 말할지

1. **소스 6개와 각각이 답하는 질문** (data-plan 1장 표) — 30초
2. **채널 선정을 데이터로 한 과정** (547 → 272 → 51, 임계값 표) — 1분
3. **파이프라인 5단계와 실제 건수** (데이터 탭 그대로) — 1분
4. **가공 규칙 셋**: 매칭(26% → 65% 가 된 이유), 사건일, 초과수익·거래량·공시 — 1분
5. **품질을 어떻게 지켰나**: 못 잡은 제목 보관, 오탐 규칙과 테스트, 표본 표시 — 30초

이 다섯 가지가 "어떤 소스에서 어떻게 가공해 무슨 가치" 에 대한 답이다.
