# 데이터 계획 — 무엇을, 어디서, 어떻게 가공해, 무슨 질문에 답하나

교수 피드백("어떤 소스에서 데이터를 가져와 어떻게 가공해 무슨 가치를 주는가")에 대한 답을 한 장으로 정리한다. 발표의 데이터 장은 이 문서를 그대로 옮긴다. 출처 표(명칭·기관·URL)는 [data-sources.md](data-sources.md), 채널 선정 근거는 [channel-selection.md](channel-selection.md).

## 1. 질문 → 데이터

| 질문 | 필요한 데이터 | 출처 | 상태 |
|---|---|---|---|
| 어떤 유튜버가 언제 무슨 종목을 말했나 | 영상 제목·게시 시각 | YouTube Data API v3 | ✅ 수집 중 (채널 51개, 1년) |
| 제목의 "삼전", "하닉", "엔비디아"가 어느 종목인가 | 종목 사전 + 별칭 | DART corpCode(국내 전 상장사) · 팀 별칭 사전 · 업비트 마켓 목록 | 시드 57 + 코인 289. DART 키 들어오면 약 2,600으로 |
| 언급 뒤 주가는 어떻게 됐나 | 일별 종가(국내·미국·코인) | 공공데이터포털 금융위 시세 · Yahoo Finance · 업비트 일봉 | ✅ (국내는 Yahoo 대체, 키 들어오면 공식 소스로) |
| 시장 전체가 오른 덕인가 | 코스피 · S&P500 · 비트코인 | Yahoo · 업비트 | ✅ |
| 언급 뒤 **관심**이 늘었나 (가격 말고) | 일별 거래량 | Yahoo · 업비트 응답에 포함(컬럼만 추가) | 🔧 D1 |
| "반도체 급등" 같이 **종목 없는 제목**도 셀 수 있나 | 업종·테마 사전 + 대표 ETF 시세 | 팀 사전 · Yahoo (KODEX 반도체 등) | 🔧 D2 |
| 언급이 **공시·실적 직후**에 몰리나 | 공시 목록(일자·유형) | DART 공시검색 API `list.json` | 🔧 D3 (키 대기) |
| 언급의 **세기**는 | 조회수·좋아요·댓글 수 | YouTube videos.list (같은 호출) | 🔧 D4 |

## 2. 가공 파이프라인 (매일 1회, GitHub Actions)

```
① market-data  사전 갱신(DART·업비트) → tracked 종목 시세·거래량 (공공데이터포털·Yahoo·업비트)
② youtube      채널 51개 업로드 목록에서 새 영상 (제목·설명·게시일·조회수)
③ mentions     제목 → 종목·테마 매칭 (긴 표현 우선, 흔한 단어 제외, 코인은 문맥 필요) → mentions / unmatched
④ market-data  새로 언급된 종목 track 켜고 시세 보충
⑤ stats        언급별 T0(첫 거래 가능일) → r5·r20·r60, 벤치마크 대비 초과수익, 거래량 변화, 요약 캐시
⑥ (D3)         공시 적재 → 언급 전후 창(−3~+3일) 집계
```

- T0 규칙: 국내 15:30 이전 게시 → 당일 종가, 이후 → 다음 거래일. 미국은 동부시간 16:00 기준. 코인은 다음 일봉(09:00 KST).
- r_h = P(T0+h거래일)/P(T0) − 1. x_h = r_h − 벤치마크 r_h. h일이 안 지났으면 null → 다음 배치가 채운다.
- 표본 수는 항상 같이 낸다. 30건 미만은 "참고용" 표시.

## 3. 추가 소스 상세

### D1 거래량 (확정, 반나절)
- Yahoo chart API `indicators.quote[0].volume`, 업비트 `candle_acc_trade_volume`, 공공데이터포털 `trqu`.
- `market.prices.volume` 컬럼 추가. stats 에 `vol_ratio` = 언급 뒤 5거래일 평균 거래량 ÷ 언급 전 20거래일 평균.
- 답: "언급 뒤 거래량이 평균 x배" — 가격이 안 올라도 관심은 늘었는지.

### D2 업종·테마 사전 (확정, 1일)
- 못 잡은 제목 1,304건 표본에서 반도체·코스피·환율·관세·2차전지·바이오·조선·방산이 반복됐다.
- 테마 → 대표 ETF 로 수익률을 잰다: 반도체 KODEX 반도체(091160), 2차전지 KODEX 2차전지산업(305720), 바이오 KODEX 바이오(244580), 조선 KODEX K-조선(?), 방산 PLUS K방산(449450), 자동차 KODEX 자동차(091180), 은행 KODEX 은행(091170), 건설 KODEX 건설(117700), 철강 KODEX 철강(117680), 게임 KODEX 게임산업(300950), 엔터 … (코드는 등록 전에 Yahoo 로 검증)
- 사전에는 `asset_type="theme"` 로 넣고 별칭에 테마 단어를 둔다. 매칭 confidence 0.6. 화면·통계에서 종목과 테마를 구분한다.
- "코스피" 자체도 테마(지수 ETF KODEX 200)로 잡아 "코스피 폭락" 류 제목을 사건으로 센다.
- 답: 매칭 성공률 26% → 50%대 기대. "종목 언급 vs 업종 언급"의 사후 수익률 비교.

### D3 DART 공시 (키 대기, 1일)
- `https://opendart.fss.or.kr/api/list.json?corp_code=&bgn_de=&end_de=&page_count=100` — 1년치 전체 조회 가능(소급 가능).
- `market.disclosures(corp_code, rcept_no, rcept_dt, report_nm, kind)`. 언급된 국내 종목만.
- 답: 언급일 전후 ±3일에 공시(실적·주요사항)가 있었던 비율. "유튜브가 공시를 따라가는가".

### D4 YouTube 좋아요·댓글 수 (시간 되면, 반나절)
- `videos.list part=statistics` 에 이미 들어 있다(likeCount, commentCount). `yt.videos` 컬럼 2개 추가.
- 답: 조회수·반응이 큰 언급일수록 뒤의 반응이 다른가(가중 통계).

## 4. 안 하는 것과 이유

| 후보 | 이유 |
|---|---|
| 자막·댓글 수집 | 공개 메타데이터만 쓴다는 원칙(저작권·개인정보). 제목만으로도 질문에 답할 수 있다 |
| 종목토론방·커뮤니티 크롤링 | 시간. 동일한 "관심" 질문은 거래량으로 답한다 |
| 네이버 뉴스 검색 API | 2026-10-07 제외. 최신 1,000건만 줘서 1년 소급이 안 되고(발표 때 2주치뿐), 팀이 과금 가능성을 피하고 싶어 함. "언급이 외부 사건을 따라가는가"는 DART 공시(1년 소급 가능)로 답한다 |
| Google Trends | 비공식 API. 차단 리스크 |
| 채널 실명 숨김(익명 집계) | 2026-10-07 팀 결정으로 실명·채널별 성적 공개로 변경. 학습용 고지 고정 |

## 5. 정직하게 말할 한계

- 제목만 보므로 "사라"인지 "조심하라"인지 모른다. 그래서 방향을 판단하지 않고 **언급 자체를 사건**으로 본다.
- 매칭은 사전 기반이라 신조어·오타는 놓친다. 못 잡은 제목을 전부 남겨 성공률을 그대로 보여준다.
- 국내 시세가 공공데이터포털 키 승인 전엔 Yahoo 대체다. 종가 기준이라 차이는 없지만 출처는 정확히 적는다.
